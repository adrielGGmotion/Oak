Setting Up Ollama with Oak

1

Install Ollama

Download from ollama.com/download or run: curl -fsSL https://ollama.com/install.sh | sh

2

Pull a Model

Run ollama pull llama3.2 (3B, ~2GB) or ollama pull gemma2 for a stronger model.

3

Configure Oak

In Oak Settings → Services → Add Service → Select "OpenAI-Compatible API". Use base URL: http://localhost:11434/v1

4

Start Chatting

Select the OpenAI-Compatible service and start chatting. Your data never leaves your machine.

🔧 How to Add a Provider to Oak

1

Get an API Key

Sign up at one of the providers above and copy your API key.

2

Open Oak Settings

Go to Settings → Services tab.

3

Add Service

Click "Add Service" and select the provider. Paste your API key.

4

Start Chatting

Select the service and start your conversation.
